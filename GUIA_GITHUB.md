# Publicar o site atualizado no GitHub

Repositório: https://github.com/brunorizzieri86-svg/vetflowcare-site

1. Guarde uma cópia da versão atual, se desejar voltar a ela depois.
2. Extraia o ZIP no computador. O index.html deve ficar na mesma pasta que CNAME e as imagens, sem uma pasta extra envolvendo tudo.
3. No GitHub, abra o repositório e escolha **Add file → Upload files**.
4. Arraste o conteúdo extraído para a raiz do repositório, preservando as pastas app/, instalar/ e tutorial/. Não envie o próprio ZIP: o GitHub Pages não o extrai.
5. Confirme o envio em **Commit changes**. O index.html antigo será substituído pelo novo.
6. Aguarde a publicação do GitHub Pages e abra https://www.vetflowcare.com.br. Atualize com Ctrl+F5 no computador para evitar cache.
7. Confira a página no celular, o logo na abertura, o menu, as telas do app, o FAQ e os botões do aplicativo e do Plano Pro.

## O que precisa subir?

O ZIP já contém o site completo. As imagens novas estão dentro do index.html, então não precisam ser enviadas separadamente. As imagens antigas dos celulares continuam como arquivos e também estão no pacote, com os mesmos nomes e caminhos.

Se você mantiver todos os arquivos existentes no repositório, basta substituir o index.html. O pacote completo está disponível para não depender de arquivos faltando.

## Não altere o domínio

Mantenha o arquivo CNAME com www.vetflowcare.com.br. Não é necessário mudar DNS, configurar o Pages novamente ou alterar a hospedagem do aplicativo.
